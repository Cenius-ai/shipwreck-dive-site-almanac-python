How the slack windows work

One spring tide reference day is published with four anchor times: high water, low water, a second high and a second low. Each site carries its own offset in minutes from the anchor that suits it, plus its own slack window length.

Anchor time plus the site offset gives the start of the window; add the site's published slack length and you have the end. The wreck page prints the anchor and the offset beside every window so you can check the arithmetic yourself.
